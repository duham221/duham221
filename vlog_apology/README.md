# فلوق اعتذار — محرّر آلي (Apology-Vlog Auto-Editor)

سكربت بايثون ينسج فلوق اعتذار شخصي تلقائياً: يأخذ مقطعك الأساسي (أنت تتكلم
للكاميرا) ومجلد ذكريات (صور وكليبات قديمة)، ويبني مونتاجاً عاطفياً كاملاً.

## الفكرة الأساسية
صوتك هو العمود الفقري ولا ينقطع أبداً. نُبقي فيديو + صوت المقطع الأساسي
متواصلَين بطول الفلوق، ونركّب الذكريات *فوق* الصورة كطبقات بقناة ألفا (دِزولڤ)،
فالصوت يستمر تحتها بلا أي قطع.

## ماذا يفعل
1. **تفريغ** المقطع الأساسي بـ`faster-whisper` بطوابع زمنية على مستوى الكلمة (عربي).
2. **كشف لحظات الإرساء** العاطفية: كلمات مثل «آسف، سامحيني، أتذكر، وعدتك، احنا»،
   أو وقفة طويلة قبل جملة ثقيلة. الذكريات تُربط بهذه اللحظات لا بتوزيع متساوٍ.
3. **الجسم (أول ~75%)**: ذكريات قليلة ومتباعدة، صور بـKen Burns بطيء، كليبات
   مكتومة الصوت، انتقالات دِزولڤ فقط، موسيقى واطية مع ducking قوي.
4. **الختام (آخر ~25%)**: مونتاج متسارع (كل وحدة أقصر)، موسيقى ترتفع تدريجياً،
   انتقالات قوية (لايت-ليك / ومضة بيضاء ناعمة / سبيد رامب / ماتش كت)، ثم إقفال
   على الوجه بتلاشٍ بطيء.
5. **لوك دافئ موحّد** على كل اللقطات (دفء + desaturation خفيف + vignette).
6. **تصدير** MP4/H.264 بنفس أبعاد ومعدل إطارات المصدر.
7. يطبع **خريطة المونتاج** ويكتب **`edl.csv`** للتعديل اليدوي.

## التشغيل
```bash
python3 -m venv venv && . venv/bin/activate
pip install faster-whisper pillow-heif numpy requests   # + ffmpeg على النظام

python assemble_apology_vlog.py \
  --base   path/to/me_talking.mp4 \
  --memories path/to/memories_folder \
  --out    out/apology_vlog.mp4 \
  --music  path/to/song.mp3   # اختياري (بدونه يُركّب سرير موسيقي دافئ)
  --name   "اسمها"            # اختياري لتقوية ذكر الاسم كلحظة إرساء
```

## المخرجات
- `out/apology_vlog.mp4` — الفلوق النهائي.
- `montage_map.txt` — خريطة المونتاج (وين كل ذكرى ولماذا، ونوع كل انتقال).
- `edl.csv` — قائمة تحرير (timeline in/out، المصدر، الانتقال) للتعديل اليدوي.
